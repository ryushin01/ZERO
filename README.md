# ZERO - 신화 덱빌딩

[![CI](https://github.com/ryushin01/ZERO/actions/workflows/ci.yml/badge.svg)](https://github.com/ryushin01/ZERO/actions/workflows/ci.yml)
![version](https://img.shields.io/badge/version-0.12.11-060403)
![JavaScript](https://img.shields.io/badge/JavaScript-ES2022-F7DF1E?logo=javascript&logoColor=black)

세계 신화 도서관 [Ark](https://github.com/ryushin01/Ark)의 신과 영웅, 아더 왕·아킬레우스·손오공 같은 전설의 영웅, 메두사·케르베로스 같은 신화 속 괴물까지 322명을 카드로 모으고, 엑스칼리버·묠니르 같은 신화 무구를 휘둘러 기록을 지우려는 괴물과 태초의 공허 ‘영(零)’에 맞서는 웹 덱빌딩 게임입니다.

**[바로 플레이하기](https://zero-ryushin01.vercel.app/)** · [Storybook](https://zero-ryushin01.vercel.app/storybook/index.html) · 설치 없이 브라우저에서 키보드나 마우스, 터치로 플레이합니다.

> **프로젝트 상태:** 프레임워크 없이 순수 자바스크립트로 만든 **포트폴리오 프로젝트**입니다. 신과 신화 계열의 소개는 Ark에서 가져왔고, Ark에 아직 없는 전설의 영웅은 위키백과로 확인해 ZERO가 같은 모양의 데이터로 더했습니다. 카드·괴물·무구 일러스트는 Mythic Battles 시리즈의 분위기를 참고해 코드(SVG)로 새로 그렸습니다. 카드 상세에는 Ark가 소장한 Wikimedia Commons 자료를 저작자·라이선스와 함께 보여 줍니다. 진행 상황은 브라우저에만 저장합니다.

## 주요 기능

| 구분      | 내용                                                                                                                                                                                                                                                                                                                                                         |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 카드      | Ark의 신과 영웅, 괴물 322명(신화·전설 계열 49개)이 모두 카드. 신·영웅·몬스터(신수·영수)·그 밖의 존재로 나뉩니다. 아서왕 전설·천일야화 등의 인물은 ZERO가 먼저 더한 뒤 Ark로 옮겼습니다. 관장 영역을 여섯 속성(戰·守·智·生·死·天)으로 묶어 효과를 계산하고, 번개의 신은 모든 적을, 속임수의 신은 비용 0으로 칩니다.                                           |
| 무구      | 묠니르, 엑스칼리버, 그람, 간디바, 여의봉, 만파식적 등 39점. 바사비 샥티처럼 전투마다 한 번만 쓰는 무구도 있습니다. 에너지를 써서 휘두르고 몇 턴 쉬며, 주인 신의 카드를 낸 턴에는 50% 강해집니다(묠니르는 바로 돌아옴). 위키백과·나무위키로 고증                                                                                                              |
| 장착      | 신·영웅의 카드에 무구·도구와 탈것·동반자를 끼워 한 장으로. 묠니르를 토르에게 끼우면 50% 강해지고, 오딘에 슬레이프니르를 태우면 결속으로 첫 턴에 손에 들어오고 비용이 줄어듭니다.                                                                                                                                                                             |
| 세력      | 같은 신화 계열을 3장 모으면 1단계, 5장이면 2단계. 한국 신화 ‘홍익인간’은 매 턴 회복, 북유럽 ‘아스가르드’는 힘 등 계열 49개마다 세력 효과(아서왕 전설 ‘원탁의 기사’ 등)                                                                                                                                                                                       |
| 세계관    | 같은 계열을 이어 내면 공명(+50%), 같은 대륙이면 울림(+25%). 헤라클레스→히드라처럼 신화 속 천적은 피해 +50%. 카드에서 Ark의 신 소개나 위키백과로 이어집니다.                                                                                                                                                                                                  |
| 일러스트  | 신·영웅·괴물 322명, 적으로 나오는 괴물 21종, 무구 39점을 코드로 그린 SVG. 먹색 옷과 종이색 살, 흔들리는 외곽선의 흑백 스케치를 신화권마다 다른 단색 배경 위에 그리고(한국 신화권은 한지 같은 회색의 흑백), 괴물은 더 어두운 배경에 둡니다. 돌진·도약·내려찍기 같은 움직이는 자세, 신마다 다른 체격·머리 모양, 오딘의 까마귀나 아테나의 올빼미 같은 동반 동물 |
| 전장      | 성역(아발론·아틀란티스 등) → 신역(올림포스·발할라·하데스의 명계 등) → 아우터 유니버스(긴눙가가프·카오스 등) 30곳. 전장마다 효과 하나와 그 신화권 카드의 지형 공명(피해·방어 등 +25%), 지도에 드물게 열리는 이차원의 균열                                                                                                                                     |
| 한 판     | 길잡이 신화, 세 장의 갈림길 지도, 괴물 21종(그렌델·키클롭스·파프니르 추가), 사건 7종, 쉼터·성소, 유물 9종, 자동 저장, 체력이 깎이면 떠오르는 숫자                                                                                                                                                                                                            |
| 다시 하기 | 판을 넘어 쌓이는 서가 복원(322명 진행도), 날짜로 모두가 같은 지도에서 겨루는 오늘의 신화와 결과 복사                                                                                                                                                                                                                                                         |
| 2인 듀얼  | 한 기기에서 번갈아 두는 대전. 클래스 116종(전사·도적·마법사·성직자와 근접·민첩·마법·성직·기타 계열) 가운데 하나를 고르면 그 속성의 신·영웅으로 덱이 무작위로 짜이고, 차례가 바뀔 때마다 상대의 패를 가립니다.                                                                                                                                                |
| 히든      | Ark에 기록되지 않은 검객 유신과 무구 영혼의 검(쌍수도). 새 기록을 시작할 때 바로 데려가거나, 사건 칸에서 드물게 열리는 ‘붉은 방’에서 만납니다. 밸런스를 일부러 깨는 성능이라 오늘의 신화에서는 시작 선택도, 붉은 방도 없습니다.                                                                                                                              |
| 접근성    | 카드·무구 모두 키보드로, 전투 결과를 화면 낭독기로 알림, 보이는 글자가 곧 이름, 움직임 끄기, 동작 줄이기 반영                                                                                                                                                                                                                                                |

## 시작하기

Node.js 26(`.nvmrc`)과 pnpm 12가 필요합니다.

```bash
corepack enable pnpm
pnpm install
pnpm dev        # http://localhost:5173
```

| 명령                                         | 설명                                                                          |
| -------------------------------------------- | ----------------------------------------------------------------------------- |
| `pnpm build` / `pnpm preview`                | 앱과 Storybook(`/storybook/`) 빌드 / 빌드 결과 실행 (`http://localhost:4173`) |
| `pnpm lint` / `pnpm lint:fsd` / `pnpm check` | ESLint / FSD 구조 / 타입 검사                                                 |
| `pnpm test`                                  | 규칙·전투·화면 단위 테스트와 자동 플레이 100판 난이도 검사                    |
| `pnpm test:e2e`                              | 프로덕션 빌드의 실제 화면과 axe 검사 (먼저 `build` 필요)                      |
| `pnpm size` / `pnpm lhci`                    | 번들 크기 예산 / Lighthouse 점수 기준 검사 (먼저 `build` 필요)                |
| `pnpm storybook`                             | Storybook 개발 서버 (`http://localhost:6006`)                                 |
| `pnpm sync:ark`                              | 옆 폴더의 Ark에서 신·계열·그림을 다시 가져오기                                |

## 프로젝트 구조

```
scripts/         Ark 데이터 동기화, Ark에 없는 전설 확장 데이터 만들기(legends)
e2e/             한 판 흐름, 키보드 조작, 저장, 화면 폭, axe 검사
src/
├─ app/          진입점, 상태 저장소, 해시 라우터, 렌더 루프, 전역 스타일
├─ pages/        title, new-run, run(지도·전투·장착·보상·쉼터·사건·결과), duel(2인 듀얼·클래스), codex, guide
├─ widgets/      site-header, card-detail, deck-view
├─ features/     run(전투 엔진, 무구 사용, 한 판의 흐름, 사건, 기록, 자동 플레이어)
├─ entities/     figure(Ark·전설 확장 데이터, 일러스트 사양), card, armament, bond(탈것·동반자), faction, battlefield, enemy, relic, map
└─ shared/       DOM 생성·패치, 일러스트 엔진, 시드 난수, 조사 붙이기, 알림, 대화상자
```
