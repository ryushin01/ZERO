# ZERO - 신화 덱빌딩

[![CI](https://github.com/ryushin01/ZERO/actions/workflows/ci.yml/badge.svg)](https://github.com/ryushin01/ZERO/actions/workflows/ci.yml)
![version](https://img.shields.io/badge/version-0.2.0-060403)
![JavaScript](https://img.shields.io/badge/JavaScript-ES2022-F7DF1E?logo=javascript&logoColor=black)

세계 신화 도서관 [Ark](https://github.com/ryushin01/Ark)의 신과 영웅 133명을 카드로 모아, 기록을 지우려는 괴물과 태초의 공허 ‘영(零)’에 맞서는 웹 덱빌딩 게임입니다.

**[바로 플레이하기](https://zero-ryushin01.vercel.app/)** · 설치 없이 브라우저에서 키보드나 마우스, 터치로 플레이합니다.

> **프로젝트 상태:** 프레임워크 없이 순수 자바스크립트로 만든 **포트폴리오 프로젝트**입니다. 신과 신화 계열의 소개와 카드 그림은 Ark에서 가져왔고, 그림은 모두 Wikimedia Commons의 퍼블릭 도메인·CC 라이선스 자료입니다(도감에서 저작자와 라이선스 표기). 진행 상황은 브라우저에만 저장합니다.

## 주요 기능

| 구분      | 내용                                                                                                                                                                    |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 카드      | Ark의 신 133명이 모두 카드. 관장 영역을 여섯 속성(戰·守·智·生·死·天)으로 묶어 효과를 계산하고, 번개의 신은 모든 적을, 속임수의 신은 비용 0으로 칩니다.                  |
| 세계관    | 같은 신화 계열을 이어 내면 공명(+50%), 같은 대륙이면 울림(+25%). 헤라클레스→히드라, 티르→펜리르처럼 신화 속 천적은 피해 +50%. 카드에서 Ark의 신 소개로 이어집니다.      |
| 한 판     | 길잡이 신화 고르기, 세 장의 갈림길 지도, 괴물 18종(정예·보스 포함), 사건 7종, 쉼터·성소, 신화 속 유물 12종, 자동 저장과 이어 하기, 체력이 깎이면 떠오르는 숫자와 흔들림 |
| 도감      | 신과 영웅 133장(대륙·속성·이름·영역 거르기), 괴물의 행동과 천적, 유물. 카드 상세에 Ark 자료 그림, 소장처, 저작자, 라이선스                                              |
| 다시 하기 | 덱에 넣은 신을 판을 넘어 기록하는 서가 복원(133명 진행도, 이번 판에 새로 복원한 신), 날짜로 모두가 같은 지도에서 겨루는 오늘의 신화와 결과 복사                         |
| 접근성    | 모든 조작을 키보드로, 전투 결과를 화면 낭독기로 알림, 보이는 글자가 곧 카드의 이름, 움직임 끄기, 동작 줄이기 설정 반영                                                  |

## 시작하기

Node.js 26(`.nvmrc`)과 pnpm 12가 필요합니다.

```bash
corepack enable pnpm
pnpm install
pnpm dev        # http://localhost:5173
```

| 명령                                         | 설명                                                       |
| -------------------------------------------- | ---------------------------------------------------------- |
| `pnpm build` / `pnpm preview`                | 프로덕션 빌드 / 빌드 결과 실행 (`http://localhost:4173`)   |
| `pnpm lint` / `pnpm lint:fsd` / `pnpm check` | ESLint / FSD 구조 / 타입 검사                              |
| `pnpm test`                                  | 규칙·전투·화면 단위 테스트와 자동 플레이 100판 난이도 검사 |
| `pnpm test:e2e`                              | 프로덕션 빌드의 실제 화면과 axe 검사 (먼저 `build` 필요)   |
| `pnpm storybook`                             | Storybook 개발 서버 (`http://localhost:6006`)              |
| `pnpm sync:ark`                              | 옆 폴더의 Ark에서 신·계열·그림을 다시 가져오기             |

## 프로젝트 구조

```
scripts/         Ark 데이터 동기화
e2e/             한 판 흐름, 키보드 조작, 저장, 화면 폭, axe 검사
src/
├─ app/          진입점, 상태 저장소, 해시 라우터, 렌더 루프, 전역 스타일
├─ pages/        title, new-run, run(지도·전투·보상·쉼터·사건·결과), codex, guide
├─ widgets/      site-header, card-detail, deck-view
├─ features/     run(전투 엔진, 한 판의 흐름, 사건, 자동 플레이어)
├─ entities/     figure(Ark 데이터), card(속성·카드 생성·앞면), enemy, relic, map
└─ shared/       DOM 생성·패치, 시드 난수, 조사 붙이기, 알림, 저장소, 대화상자
```
