# 카드 규칙

카드 효과는 손으로 정하지 않고, Ark에 적힌 신의 관장 영역(`domains`)에서 계산합니다. Ark에 아직 없는 인물을 ZERO가 먼저 더할 때도(전설 확장) 같은 모양의 데이터로 같은 계산을 거칩니다. 같은 신이라면 Ark에서 읽은 성격이 카드에도 그대로 드러납니다. 계산은 `src/entities/card/model/`에 있습니다.

## 1. 영역 → 속성

관장 영역 130여 가지를 여섯 속성으로 묶었습니다. 맨 앞에 적힌 영역의 속성이 **주 속성**, 그다음으로 다른 속성의 영역이 **보조 속성**입니다.

| 속성    | 주 효과                                        | 보조 효과        | 영역의 예                        |
| ------- | ---------------------------------------------- | ---------------- | -------------------------------- |
| 戰 전투 | 피해                                           | 작은 피해        | 전쟁, 번개, 힘, 사냥, 영웅, 불   |
| 守 수호 | 방어                                           | 작은 방어        | 수호, 바다, 산, 대지, 맹세, 질서 |
| 智 지혜 | 카드 뽑기                                      | 1장 뽑기         | 지혜, 예언, 마법, 시, 운명, 전령 |
| 生 생명 | 방어와 회복                                    | 회복             | 풍요, 사랑, 치유, 비, 부활, 출산 |
| 死 죽음 | 침식                                           | 취약             | 저승, 죽음, 혼돈, 밤, 달, 뱀     |
| 天 하늘 | 힘(왕권), 모든 적 피해(태양), 매 턴 방어(창조) | 에너지 또는 방어 | 하늘, 왕권, 태양, 빛, 창조, 건국 |

영역 하나가 효과의 모양을 바꾸기도 합니다.

| 영역                         | 바뀌는 점                   |
| ---------------------------- | --------------------------- |
| 번개, 천둥                   | 모든 적을 칩니다            |
| 폭풍, 바람                   | 두 번 나눠 칩니다           |
| 속임수, 장난, 꾀, 도둑, 변신 | 비용 0, 효과는 작게         |
| 부활, 재생, 불사, 불멸       | 보존(턴이 끝나도 손에 남음) |

## 2. 희귀도와 몫

Ark에서 그 신화의 첫 번째로 소개된 신은 전설, 두세 번째는 희귀, 나머지는 일반입니다. 희귀도마다 효과의 몫이 있고, 기본 카드 「필봉」(비용 1, 피해 6)을 1로 둡니다.

| 희귀도 | 비용 | 몫   | 속임수의 신 (비용 0) |
| ------ | ---- | ---- | -------------------- |
| 일반   | 1    | 1.35 | 0.8                  |
| 희귀   | 1    | 1.6  | 0.95                 |
| 전설   | 2    | 3.2  | 1.25                 |

보조 속성이 있으면 주 속성에 몫의 75%, 보조 속성에 35%를 씁니다. 몫 1은 피해 6, 모든 적 피해 4.5, 두 번 치기 3.2씩, 방어 5.5, 카드 1.6장, 침식 3.5, 힘 1.4에 해당합니다. 강화하면 수치가 약 33%(최소 2) 오르고, 뽑기·힘·취약은 1 오릅니다.

예) 제우스(하늘, 번개, 법과 질서): 주 속성 天(왕권) → 힘 3, 보조 속성 戰(번개) → 모든 적에게 피해 5. 권능 카드.

- 그 턴에 주인 신의 카드를 냈다면 효과가 50% 늘어납니다. 묠니르만은 대신 대기시간 없이 돌아옵니다.
- 주인 신을 천적으로 둔 괴물에게는 무구도 천적으로 통합니다. (비슈누의 원반과 라후 등)
- 길잡이 신화에 전해지는 무구 하나를 들고 떠나고(없으면 무작위), 정예를 물리치면 둘 가운데 하나를 더 고릅니다. 최대 3점까지 듭니다.

### 히든 무구와 카드

사건 칸에서 8% 확률(덱에 유신이 없을 때)로 ‘붉은 방’이 열립니다. 최대 체력 10을 내면 히든 카드 **유신**과 무구 **영혼의 검**을 함께 얻습니다. 둘 다 일부러 밸런스를 깨는 성능이며 `src/entities/card/model/hidden.js`, `HIDDEN_ARMAMENTS`에 있습니다.

| 이름      | 비용·쉬는 턴  | 효과                                        |
| --------- | ------------- | ------------------------------------------- |
| 유신      | 0             | 모든 적에게 피해 15씩 2번, 힘 2, 보존       |
| 영혼의 검 | 에너지 0, 1턴 | 모든 적에게 피해 24(방어 무시), 체력 6 회복 |

- 영혼의 검의 생김새는 조선의 두 손 칼 쌍수도(날 150cm, 둥근 놋쇠 코등이, 붉은 실 자루)를 따랐고, 혼을 벤다는 이야기는 ZERO가 지었습니다.
- 히든은 보상·길잡이 무구·서가 복원 진행도에 들지 않고, 찾은 뒤에만 도감의 ‘히든’ 칸에 보입니다. 무구 자리(3점)를 넘어도 함께 듭니다.

## 4. 세력

같은 신화 계열의 신을 덱에 3장 모으면 1단계, 5장이면 2단계 효과가 전투에 붙습니다. 정의는 `src/entities/faction/model/factions.js`에 있습니다.

| 세력 (계열)                | 효과 (1단계 / 2단계)                |
| -------------------------- | ----------------------------------- |
| 올림포스 열두 신 (그리스)  | 전투 시작 시 방어 6 / 12            |
| 아스가르드 (북유럽)        | 전투 시작 시 힘 1 / 2               |
| 두 땅의 신들 (이집트)      | 전투 시작 시 모든 적에게 약화 1 / 2 |
| 윤회의 바퀴 (인도)         | 전투가 끝나면 체력 4 / 8 회복       |
| 다카마가하라 (일본)        | 첫 턴 에너지 +1 / +2                |
| 홍익인간 (한국)            | 매 턴 시작에 체력 1 / 2 회복        |
| 곤륜 (중국)                | 첫 턴 카드 1 / 2장 더               |
| 운명의 서판 (메소포타미아) | 공명 +25%p / +50%p                  |
| 투어허 데 다넌 (켈트)      | 전투 시작 시 모든 적에게 침식 3 / 6 |
| 칼레발라 (핀란드)          | 매 턴 시작에 방어 2 / 4             |
| 포폴 부 (마야)             | 전투 시작 시 모든 적에게 취약 1 / 2 |
| 다섯 번째 태양 (아즈텍)    | 전투 시작 시 모든 적에게 피해 4 / 8 |

나머지 계열은 신화권(그리스·북방·켈트·이집트·근동·인도·동아시아·아메리카·아프리카·오세아니아·북서 해안)의 공통 세력을 씁니다.

## 5. 전투

- 턴마다 에너지 3, 카드 5장. 손은 최대 10장이고, 뽑을 카드가 없으면 버린 카드를 섞습니다.
- 피해 = (카드 수치 × 공명) + 힘 → 약화면 ×0.75 → 천적이면 ×1.5 → 대상이 취약하면 ×1.5. 방어가 먼저 막습니다.
- **공명**: 직전에 낸 카드와 신화 계열이 같으면 피해·방어·회복·침식 ×1.5. **울림**: 대륙만 같으면 ×1.25. 기본 카드는 고리를 끊습니다.
- **천적**: 괴물마다 신화 속에서 맞섰던 신(예: 헤라클레스→히드라, 티르·오딘→펜리르, 비슈누→라후), 계열(크레타의 신들→미노타우로스), 영역(창조의 신→영(零))이 있습니다.
- 침식은 턴이 시작될 때 체력을 깎고 1 줄어듭니다. 취약·약화는 턴이 끝날 때 1 줄어듭니다.
- 괴물은 정해진 순서로 행동하고, 다음 행동을 미리 보여 줍니다. 도깨비만 무작위로 고릅니다.

## 6. 한 판

- 길잡이 신화(신이 셋 이상인 계열 가운데 셋 중 하나)를 고르면 그 신화의 희귀·일반 카드 한 장씩과 기본 카드 9장으로 시작합니다.
- 장마다 7층 × 3칸 지도와 보스. 첫 층은 전투, 보스 앞 층은 쉼터입니다.
- 카드 보상의 35%는 길잡이 신화에서 나옵니다. 정예는 유물 하나, 보스는 유물 셋 중 하나와 전설 카드 보상을 줍니다.
- 장이 바뀌면 잃은 체력의 60%를 되찾습니다.

## 7. 난이도

`src/features/run/lib/autoplay.js`의 자동 플레이어는 카드 점수만 보고 두며, 공명이나 천적을 계획하지 않습니다. 무구를 남은 에너지로만 쓰는 이 봇의 승률을 약 15%에 맞추고, 테스트가 3~40% 범위와 1장 패배 50% 미만을 지키는지 확인합니다. 마지막 보스 영(零)에서 가장 많이 쓰러지도록 맞췄습니다.
