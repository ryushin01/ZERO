# 카드 규칙

카드 효과는 손으로 정하지 않고, Ark에 적힌 신의 관장 영역(`domains`)에서 계산합니다. Ark에 아직 없는 인물을 ZERO가 먼저 더할 때도(전설 확장) 같은 모양의 데이터로 같은 계산을 거칩니다. 같은 신이라면 Ark에서 읽은 성격이 카드에도 그대로 드러납니다. 계산은 `src/entities/card/model/`에 있습니다.

## 1. 영역 → 속성

관장 영역 130여 가지를 여섯 속성으로 묶었습니다. 맨 앞에 적힌 영역의 속성이 **주 속성**, 그다음으로 다른 속성의 영역이 **보조 속성**입니다.

| 속성    | 주 효과                                        | 보조 효과        | 영역의 예                        |
| ------- | ---------------------------------------------- | ---------------- | -------------------------------- |
| 戰 전투 | 피해                                           | 작은 피해        | 전쟁, 번개, 힘, 사냥, 영웅, 불   |
| 守 수호 | 방어                                           | 작은 방어        | 수호, 바다, 산, 대지, 맹세, 질서 |
| 智 지혜 | 카드 뽑기                                      | 1장 뽑기         | 지혜, 예언, 마법, 시, 운명, 전령 |
| 生 생명 | 방어와 회복                                    | 회복             | 풍요, 사랑, 치유, 비, 부활, 출산 |
| 死 죽음 | 침식                                           | 취약             | 저승, 죽음, 혼돈, 밤, 달, 뱀     |
| 天 하늘 | 힘(왕권), 모든 적 피해(태양), 매 턴 방어(창조) | 에너지 또는 방어 | 하늘, 왕권, 태양, 빛, 창조, 건국 |

영역 하나가 효과의 모양을 바꾸기도 합니다.

| 영역                         | 바뀌는 점                   |
| ---------------------------- | --------------------------- |
| 번개, 천둥                   | 모든 적을 칩니다            |
| 폭풍, 바람                   | 두 번 나눠 칩니다           |
| 속임수, 장난, 꾀, 도둑, 변신 | 비용 0, 효과는 작게         |
| 부활, 재생, 불사, 불멸       | 보존(턴이 끝나도 손에 남음) |

## 2. 희귀도와 몫

Ark에서 그 신화의 첫 번째로 소개된 신은 전설, 두세 번째는 희귀, 나머지는 일반입니다. 희귀도마다 효과의 몫이 있고, 기본 카드 「필봉」(비용 1, 피해 6)을 1로 둡니다.

| 희귀도 | 비용 | 몫   | 속임수의 신 (비용 0) |
| ------ | ---- | ---- | -------------------- |
| 일반   | 1    | 1.35 | 0.8                  |
| 희귀   | 1    | 1.6  | 0.95                 |
| 전설   | 2    | 3.2  | 1.25                 |

보조 속성이 있으면 주 속성에 몫의 75%, 보조 속성에 35%를 씁니다. 몫 1은 피해 6, 모든 적 피해 4.5, 두 번 치기 3.2씩, 방어 5.5, 카드 1.6장, 침식 3.5, 힘 1.4에 해당합니다. 강화하면 수치가 약 33%(최소 2) 오르고, 뽑기·힘·취약은 1 오릅니다.

예) 제우스(하늘, 번개, 법과 질서): 주 속성 天(왕권) → 힘 3, 보조 속성 戰(번개) → 모든 적에게 피해 5. 권능 카드.

- 주인 신을 천적으로 둔 괴물에게는 무구도 천적으로 통합니다. (비슈누의 원반과 라후 등)
- 길잡이 신화에 전해지는 무구 하나를 들고 떠나고(없으면 무작위), 정예를 물리치면 둘 가운데 하나를 더 고릅니다. 최대 3점까지 듭니다.

### 히든 무구와 카드

새 기록을 시작할 때 ‘히든 캐릭터 유신과 함께 시작’을 켜 두면(기본) 히든 카드 **유신**과 무구 **영혼의 검**을 처음부터 듭니다. 끄고 시작하면 사건 칸에서 8% 확률로 ‘붉은 방’이 열리고, 최대 체력 10을 내면 둘을 함께 얻습니다. 오늘의 신화에서는 시작 선택이 없고 붉은 방도 열리지 않습니다. 영혼의 검은 무구 자리(3점)에 세지 않으므로 정예 보상으로 보통 무구를 세 점까지 더 모을 수 있습니다. 둘 다 일부러 밸런스를 깨는 성능이며 `src/entities/card/model/hidden.js`, `HIDDEN_ARMAMENTS`에 있습니다.

| 이름      | 비용·쉬는 턴  | 효과                                        |
| --------- | ------------- | ------------------------------------------- |
| 유신      | 0             | 모든 적에게 피해 15씩 2번, 힘 2, 보존       |
| 영혼의 검 | 에너지 0, 1턴 | 모든 적에게 피해 24(방어 무시), 체력 6 회복 |

- 영혼의 검의 생김새는 조선의 두 손 칼 쌍수도(날 150cm, 둥근 놋쇠 코등이, 붉은 실 자루)를 따랐고, 혼을 벤다는 이야기는 ZERO가 지었습니다.
- 히든은 보상·길잡이 무구·서가 복원 진행도에 들지 않고, 도감의 ‘히든’ 칸에 따로 보입니다. 무구 자리(3점)를 넘어도 함께 듭니다.

### 장착

지도에서 ‘장착하기’를 누르면 신·영웅의 카드마다 **무구·도구 칸**과 **탈것·동반자 칸**에 하나씩 끼울 수 있습니다. 규칙은 `src/entities/bond/model/bonds.js`와 `src/features/run/model/combat.js`에 있습니다.

- 무구: 그 카드를 낼 때 무구 효과가 에너지와 대기시간 없이 함께 터집니다. 주인 신의 카드면 50% 강해집니다(뽑기 같은 작은 수는 절반, 최소 1을 더함). 카드에 끼운 무구는 사서가 따로 휘두르지 않습니다.
- 탈것·동반자: 아래 카드를 다른 카드에 끼우면 덱에서 빠져 한 장이 되고, 그 카드를 낼 때 키워드가 함께 터집니다. 빼면 덱으로 돌아오고, 끼운 카드를 덜어 내도 돌아옵니다.

| 키워드 | 효과                            | 탈것·동반자                |
| ------ | ------------------------------- | -------------------------- |
| 기동   | 카드 1장 뽑기                   | 케이론                     |
| 선제   | 전투 첫 턴에 반드시 손에 들어옴 | 슬레이프니르               |
| 비행   | 받는 다음 공격 1회 피해 절반    | 페가수스, 투룰             |
| 정찰   | 모든 적에게 약화 1              | 후긴과 무닌                |
| 수호   | 방어 5                          | 케르베로스, 스핑크스, 바롱 |
| 치유   | 체력 4 회복                     | 베누, 옥토끼               |

신화 속 짝이면 키워드 대신 결속 효과가 붙습니다. 짝은 Ark의 탈것·동반자 데이터를 따르고(`sync:ark`), 효과는 아래와 같습니다.

| 결속                  | 효과                                        |
| --------------------- | ------------------------------------------- |
| 오딘 + 슬레이프니르   | 선제, 비용 1 감소, 카드 1장 뽑기            |
| 오딘 + 후긴과 무닌    | 모든 적에게 약화 1, 카드 2장 뽑기           |
| 벨레로폰 + 페가수스   | 받는 공격 2회 피해 절반, 모든 적에게 취약 1 |
| 페르세우스 + 페가수스 | 받는 다음 공격 1회 피해 절반, 카드 1장 뽑기 |
| 하데스 + 케르베로스   | 방어 8, 모든 적에게 침식 2                  |
| 항아 + 옥토끼         | 체력 6 회복, 방어 4                         |

## 4. 세력

같은 신화 계열의 신을 덱에 3장 모으면 1단계, 5장이면 2단계 효과가 전투에 붙습니다. 정의는 `src/entities/faction/model/factions.js`에 있습니다.

| 세력 (계열)                | 효과 (1단계 / 2단계)                |
| -------------------------- | ----------------------------------- |
| 올림포스 열두 신 (그리스)  | 전투 시작 시 방어 6 / 12            |
| 아스가르드 (북유럽)        | 전투 시작 시 힘 1 / 2               |
| 두 땅의 신들 (이집트)      | 전투 시작 시 모든 적에게 약화 1 / 2 |
| 윤회의 바퀴 (인도)         | 전투가 끝나면 체력 4 / 8 회복       |
| 다카마가하라 (일본)        | 첫 턴 에너지 +1 / +2                |
| 홍익인간 (한국)            | 매 턴 시작에 체력 1 / 2 회복        |
| 곤륜 (중국)                | 첫 턴 카드 1 / 2장 더               |
| 운명의 서판 (메소포타미아) | 공명 +25%p / +50%p                  |
| 투어허 데 다넌 (켈트)      | 전투 시작 시 모든 적에게 침식 3 / 6 |
| 칼레발라 (핀란드)          | 매 턴 시작에 방어 2 / 4             |
| 포폴 부 (마야)             | 전투 시작 시 모든 적에게 취약 1 / 2 |
| 다섯 번째 태양 (아즈텍)    | 전투 시작 시 모든 적에게 피해 4 / 8 |

나머지 계열은 신화권(그리스·북방·켈트·이집트·근동·인도·동아시아·아메리카·아프리카·오세아니아·북서 해안)의 공통 세력을 씁니다.

## 5. 전장

한 판은 장마다 그 영역의 전장 하나를 지납니다. 1장은 성역, 2장은 신역, 3장은 아우터 유니버스이고, 어느 전장인지는 시드로 정해 오늘의 신화도 모두 같습니다. 정의는 `src/entities/battlefield/model/battlefields.js`에 있습니다.

| 영역                  | 전장                                                                                                                                |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 성역 (1장)            | 아발론, 카멜롯, 아틀란티스, 아르카디아, 툴레, 이스, 샹그릴라, 샴발라, 무릉도원, 이어도, 엘도라도, 아스틀란                          |
| 신역 (2장)            | 올림포스, 아스가르드, 발할라, 수미산, 곤륜산, 다카마가하라, 딜문, 아아루, 엘리시온, 티르 나 노그, 하데스의 명계, 요미노쿠니, 시발바 |
| 아우터 유니버스 (3장) | 긴눙가가프, 카오스, 누, 혼돈, 압주                                                                                                  |

- 전장마다 효과가 하나 있습니다. 세력과 같은 종류(전투 시작 방어·힘, 매 턴 방어·회복, 첫 턴 에너지·뽑기, 전투 뒤 회복, 적에게 약화·취약·침식·피해)에 더해, ‘밀려드는 바다’(턴이 끝날 때 사서와 모든 적이 피해, 방어로 막음)와 ‘적의 힘’(모든 적이 힘을 지니고 시작)이 있습니다. 세력과 전장의 같은 효과는 더해집니다.
- 지형 공명: 전장이 속한 신화권의 카드는 피해·방어·회복·침식이 25% 늘어납니다. 공명·울림과 같은 범위라 카드 뽑기·에너지·힘 같은 개수는 그대로이고, 공명·울림과 곱해집니다.
- 이차원: 지도의 가운데 층에 드물게 균열이 열립니다(약 4%). 지금 장과 다른 영역의 전장 하나가 겹친 곳에서 정예와 싸우고, 이기면 유물 둘 가운데 하나를 고릅니다.

## 6. 2인 듀얼

`#/duel`에서 한 기기로 두 사람이 번갈아 둡니다. 엔진과 클래스는 `src/pages/duel/model/`에 있습니다.

- 클래스 116종은 나무위키 「클래스(게임 용어)」의 갈래(기본 클래스의 근접·민첩·마법·성직, 기타 클래스)대로 모은 일반적인 직업 이름이고, 특정 게임의 고유 직업은 넣지 않았습니다. 기본 클래스는 전사·도적·마법사·성직자입니다.
- 클래스마다 능력 하나(시작 방어, 매 턴 방어·회복·뽑기, 첫 턴 에너지, 반격, 흡혈, 독, 관통, 분노, 피의 대가, 회피, 상대 약화·취약, 소환, 운, 최대 체력, 추가 피해)와 덱 속성 한두 가지가 있습니다.
- 덱은 그 속성의 신·영웅 카드 10장(전설은 두 장까지)과 필봉 2장, 서가 2장을 무작위로 섞어 짭니다.
- 체력 60(농부는 75), 차례마다 에너지 3과 카드 5장. 피해·약화·취약·침식은 상대에게, 방어·회복·힘·뽑기·에너지는 자신에게 겁니다. 약화·취약은 자기 차례가 끝날 때 1씩 줄어듭니다.
- 차례가 끝나면 넘기기 화면이 나와 다음 사람의 패를 가립니다. ‘패 보기’를 눌러야 손이 보입니다.

## 7. 전투

- 턴마다 에너지 3, 카드 5장. 손은 최대 10장이고, 뽑을 카드가 없으면 버린 카드를 섞습니다.
- 피해 = (카드 수치 × 공명) + 힘 → 약화면 ×0.75 → 천적이면 ×1.5 → 대상이 취약하면 ×1.5. 방어가 먼저 막습니다.
- **공명**: 직전에 낸 카드와 신화 계열이 같으면 피해·방어·회복·침식 ×1.5. **울림**: 대륙만 같으면 ×1.25. 기본 카드는 고리를 끊습니다.
- **천적**: 괴물마다 신화 속에서 맞섰던 신(예: 헤라클레스→히드라, 티르·오딘→펜리르, 비슈누→라후), 계열(크레타의 신들→미노타우로스), 영역(창조의 신→영(零))이 있습니다.
- 침식은 턴이 시작될 때 체력을 깎고 1 줄어듭니다. 취약·약화는 턴이 끝날 때 1 줄어듭니다.
- 괴물은 정해진 순서로 행동하고, 다음 행동을 미리 보여 줍니다. 도깨비만 무작위로 고릅니다.

## 8. 한 판

- 길잡이 신화(신이 셋 이상인 계열 가운데 셋 중 하나)를 고르면 그 신화의 희귀·일반 카드 한 장씩과 기본 카드 9장으로 시작합니다.
- 장마다 7층 × 3칸 지도와 보스. 첫 층은 전투, 보스 앞 층은 쉼터입니다.
- 카드 보상의 35%는 길잡이 신화에서 나옵니다. 정예는 유물 하나, 보스는 유물 셋 중 하나와 전설 카드 보상을 줍니다.
- 장이 바뀌면 잃은 체력의 60%를 되찾습니다.

## 9. 난이도

`src/features/run/lib/autoplay.js`의 자동 플레이어는 카드 점수만 보고 두며, 공명이나 천적을 계획하지 않습니다. 무구를 남은 에너지로만 쓰는 이 봇의 승률을 약 15%에 맞추고, 테스트가 3~40% 범위와 1장 패배 50% 미만을 지키는지 확인합니다. 마지막 보스 영(零)에서 가장 많이 쓰러지도록 맞췄습니다.
