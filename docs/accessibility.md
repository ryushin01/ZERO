# 접근성 점검 (KWCAG 2.2)

axe 검사를 통과해도 KWCAG를 모두 지킨 것은 아니므로, 항목마다 직접 확인한 내용을 적습니다. 항목 번호는 [비공식 정리본](https://a11ykr.github.io/kwcag22/) 기준입니다.

| 항목                          | 대응                                                                                                                                                        |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 5.1.1 대체 텍스트             | 카드 그림은 카드 이름이 있으므로 `alt=""`. 카드 상세와 사건 화면의 그림은 Ark의 대체 텍스트를 씁니다. 첫 화면 고리는 `aria-hidden`.                         |
| 5.3.1 표의 구성               | 도움말의 속성 표에 `caption`과 `th scope`. 좁은 화면에서는 이름과 `tabindex="0"`이 있는 영역 안에서 가로로 스크롤합니다.                                    |
| 5.3.2 콘텐츠의 선형구조       | 카드는 DOM을 이름 → 계열 → 효과 → 비용 순서로 두고, 보이는 자리는 CSS로 옮깁니다.                                                                           |
| 5.4.1 색에 무관한 인식        | 상태(약화·취약·침식), 공명·울림·천적, 지도 칸의 상태(지금·지나온·갈 수 없음)를 모두 글자로 알립니다.                                                        |
| 5.4.3 명도 대비               | 어두운 표면 보조 글자 7.07:1, 밝은 표면 5.71:1, 신호색 7.17:1·5.43:1, 카드 안 보조 글자 6.16:1                                                              |
| 6.1.1 키보드 사용 보장        | 모든 조작이 버튼과 링크. 카드를 고른 뒤 대상 버튼으로 초점이 옮겨 가고, Esc로 취소합니다.                                                                   |
| 6.1.2 초점 이동과 표시        | 카드를 내면 옆 카드로, 화면이 바뀌면 제목으로 초점을 옮깁니다. 대화상자를 닫으면 연 버튼으로 돌아갑니다. `:focus-visible` 윤곽선.                           |
| 6.1.4 문자 단축키             | 문자 단축키를 쓰지 않습니다. (Esc만 사용)                                                                                                                   |
| 6.2.1 응답시간 조절           | 시간 제한이 없습니다. 턴은 직접 끝냅니다.                                                                                                                   |
| 6.2.2 정지 기능 제공          | 첫 화면의 도는 고리, 지도 칸의 숨쉬기 효과, 전투의 떠오르는 숫자와 흔들림은 ‘움직임’ 버튼(첫 화면, 도움말)으로 멈춥니다. 운영체제의 동작 줄이기를 따릅니다. |
| 6.4.1 반복 영역 건너뛰기      | ‘본문 바로가기’ 링크                                                                                                                                        |
| 6.4.2 제목 제공               | 화면마다 `document.title`과 `h1`을 바꿉니다.                                                                                                                |
| 6.5.3 레이블과 네임           | 카드 버튼에 `aria-label`을 두지 않고, 보이는 글자가 그대로 이름이 됩니다.                                                                                   |
| 7.1.1 기본 언어 표시          | `lang="ko"`, 영문 이름과 표어에 `lang="en"`                                                                                                                 |
| 7.2.1 사용자 요구에 따른 실행 | Ark와 Wikimedia로 가는 링크는 새 창임을 글자로 알립니다.                                                                                                    |
| 7.3.1 오류 정정               | 진행 중인 판이 있으면 새 판을 시작하기 전에 알리고, 기록 지우기는 확인을 받습니다. 에너지가 모자란 카드를 누르면 이유를 알립니다.                           |
| 5.4.1 전투 효과               | 떠오르는 숫자는 `aria-hidden` 장식이고, 같은 내용을 전투 기록과 `role="status"` 알림으로 전합니다.                                                          |
| 8.2.1 웹 애플리케이션 접근성  | 네이티브 `<dialog>`, 고르기 버튼에 `aria-pressed`, 낼 수 없는 카드에 `aria-disabled`, 전투 결과는 `role="status"`로 알립니다.                               |
